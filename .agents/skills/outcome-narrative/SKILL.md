# 事後對帳正文

用一般人看得懂的句子說明這張表。不要用 chip_regime、verdict、excess 這類英文。

輸出格式（Markdown 正文，不要再寫最上層標題）：
- 只能使用下方對帳表。不可發明股號、百分比、價格或日期
- 準確率只用表上的「準確率句」。要寫準確率就整句照抄，不可把中性、未過門檻、尚未成熟算進分母
- 有方向的每一筆，必須把該列「人話：」後面的整句原樣貼上，單獨一行。不要改寫，不要改數字
- 人話已經說明結算日只是對帳用的收盤，以及這段是比大盤強還是比大盤弱。不要再把正的超額說成結算日換成另一個方向
- 可計分件數為 0 時，第一節只寫「還沒有可以計分的判斷」
- 不可用 1 日、3 日或 10 日超額代替這次的 5 個交易日
- 不可寫目標價、穩賺、一定漲、建議買、建議賣

三個段落標題必須一字不差：

## 有方向的判斷
先寫一句：「下面檢查的是判斷日當時的方向。」
然後每一筆有方向的列，原句貼上人話。
最後若要寫準確率，整句照抄「準確率句」。
可計分件數為 0 時，這一節只寫「還沒有可以計分的判斷」。

## 還不能計分
件數大於 0 的每一列都要寫出股號，讓人知道是哪一檔沒拿來算。數字用表上的件數，不要自己舉例。
中性：寫出股號、「中性」和件數，再補「當天沒有明確方向，所以不拿來算準不準。」
未過門檻：寫出股號、「未過門檻」和件數，再補「漲跌跟大盤差不多，分不出強弱。」
尚未成熟：寫出股號、「尚未成熟」和件數，再補「還沒走完 5 個交易日。」
三種件數都是 0 就寫「這批沒有不能計分的列。」
這一節不要寫命中、相反、看對、看錯、偏多、偏空。

## 該動哪一層
依失敗件數寫下一步，用白話，不要只丟術語。
判斷件數大於 0：寫方向看反是因為判斷日的分類規則不對，要改的是這個分類，並必須出現「籌碼歸類」。不要寫成文章寫得不好。
寫作件數大於 0：寫「寫作」，並寫出表上的 issue code。
作業件數大於 0：寫「產報沒跑完」。
三者都是 0：寫「沒有要改的層」。
有失敗時不要再寫「沒有要改的層」。沒有判斷失敗就不要寫「籌碼」。沒有寫作失敗就不要寫「寫作」。沒有作業失敗就不要寫「產報」。
