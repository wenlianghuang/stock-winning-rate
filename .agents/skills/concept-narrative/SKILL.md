# 題材新聞正文

輸出格式（繁體中文，台灣用語）：
- 只能使用下方事件表。不要讀其他檔案，不要用籌碼，不要補事件表裡沒有的數字，不要下買賣建議
- 沒有出現在該事件 mentioned_ids 的股號，不要寫成被點名或被提到
- 這頁的結論只寫報告日當天、台北時間 13:30 以後的收盤。前一日的收盤、當天的盤中和盤前，都不在下面的事件表裡，也不能寫進「收盤後」或「來源列表」
- 不要寫「稿面寫了」「稿面敘述」「稿面記載」，也不要逐則說明摘要沒寫到什麼
- 「看法」是這頁的主體。依照今天的收盤後新聞，寫出你的判斷和結論，不要改寫新聞
- 先寫結論：這批新聞對這個題材代表什麼、不代表什麼。再寫理由：是在講產業變化還是特定股票的資金進出、同一件事被寫很多次會不會把分量放大、公告或合作若沒有接到報價、產能、出貨就不能說成營運轉折
- 若有「與前一日收盤」，用一句話寫違逆或順從，結論仍以今日為準
- 看法完全不要阿拉伯數字、股號、代表標題，也不要逐則複述
- 不要加工作摘要
- 不要寫「和前一份的差異」，這段由程式附在通過驗證的正文後面
- 完整正文印在 stdout

三個段落標題必須一字不差：

## 看法
寫判斷和結論。不要條列標題，不要寫數字。

## 收盤後
- 一件一行：代表標題，冒號，稿子寫的事實。數字照稿寫一次。
- 不要解釋。不要寫相差、係將、誤作、折合、不宜、這代表、意味、換言之、也就是說。
- 不要比較兩稿差多少，不要換算單位，不要寫這件事的意義。意義只放在看法。

## 來源列表
- 代表標題｜媒體｜網址
只列報告日當天的收盤事件。

規則：
- 「收盤後」和「來源列表」的標題只能用報告日當天收盤事件的 title，或該事件 sources 裡的 title
- 「看法」不能出現代表標題，也不能出現阿拉伯數字
- 股號只能出現在「收盤後」，而且只能來自該事件的 mentioned_ids
